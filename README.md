# Ocean TD

Roblox underwater tower defense (feed-the-wave). Phase 1: plots + persistence groundwork.

## Quick start
1. Open `Ocean TD.rbxl` in Studio.
2. Place `MasterTerrainBox`, run plot plugin Spawn/Update Previews ([docs/STUDIO_CONTRACT.md](docs/STUDIO_CONTRACT.md)).
3. `aftman install` then `rojo serve` — connect Rojo plugin to the open place.
4. Enable Studio DataStore API access for save/load tests.
5. Read [docs/PROJECT_OVERVIEW.md](docs/PROJECT_OVERVIEW.md) → [docs/SYSTEMS_INDEX.md](docs/SYSTEMS_INDEX.md).
